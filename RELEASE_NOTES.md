## Sonos Macbar 0.1.1

Small usability update focused on live status and a cleaner first-run experience.

- Live volume refresh keeps the slider in sync when volume changes outside the app, for example with a TV or Sonos remote.
- The control panel now shows the current playback source, such as TV Audio.
- The source label is shown with a compact icon instead of extra text.
- Keychain credentials now use one combined entry to reduce repeated macOS permission prompts.
- README screenshots have been updated to show the current connect, control, and settings screens.
